# R2 - DOM II: Ejercicios de Manipulación del DOM

Este directorio contiene 6 ejercicios sencillos y progresivos sobre manipulación del DOM con JavaScript.

## 📚 Lista de Ejercicios

### 1️⃣ Ejercicio 1 - Cambiar Texto
**Concepto:** Modificar el contenido de texto de elementos.
- Cambia el texto de un párrafo al hacer clic en un botón.
- 📂 Carpeta: `Ejercicio1-CambiarTexto`

### 2️⃣ Ejercicio 2 - Cambiar Estilos
**Concepto:** Modificar estilos CSS desde JavaScript.
- Cambia el color, forma y rotación de una caja.
- 📂 Carpeta: `Ejercicio2-CambiarEstilos`

### 3️⃣ Ejercicio 3 - Añadir Elementos
**Concepto:** Crear y añadir nuevos elementos al DOM.
- Añade nuevos elementos a una lista dinámicamente.
- 📂 Carpeta: `Ejercicio3-AñadirElementos`

### 4️⃣ Ejercicio 4 - Eliminar Elementos
**Concepto:** Eliminar elementos existentes del DOM.
- Elimina tareas de una lista al hacer clic en el botón ×.
- 📂 Carpeta: `Ejercicio4-EliminarElementos`

### 5️⃣ Ejercicio 5 - Manipular Atributos
**Concepto:** Cambiar atributos de elementos (src, alt, etc.).
- Alterna entre dos imágenes cambiando el atributo `src`.
- 📂 Carpeta: `Ejercicio5-ManipularAtributos`

### 6️⃣ Ejercicio 6 - Eventos Básicos
**Concepto:** Responder a eventos del usuario.
- Muestra en tiempo real lo que escribes en un input.
- 📂 Carpeta: `Ejercicio6-EventosBasicos`

## 🚀 Cómo usar

1. Navega a la carpeta del ejercicio que quieras probar.
2. Abre el archivo `index.html` en tu navegador.
3. Interactúa con la página para ver cómo funciona.

## 📁 Estructura de cada ejercicio

Cada ejercicio contiene:
- `index.html` - Estructura HTML
- `styles.css` - Estilos CSS modernos
- `script.js` - Lógica JavaScript con comentarios

## 💡 Características

- ✅ **Sencillos:** Código mínimo y fácil de entender
- ✅ **Progresivos:** De más simple a más complejo
- ✅ **Comentados:** Explicaciones en español
- ✅ **Modernos:** Diseños coloridos con gradientes y animaciones
- ✅ **Autocontenidos:** Cada ejercicio funciona independientemente
